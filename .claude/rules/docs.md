# Documentation Rules

- In .md files: use plain-text math (Unicode symbols ok), never LaTeX dollar signs
- In .tex files: equations are primary content, minimize prose
- Notation: e_{dz i} for tracking error, "observer" (not "PP")
- When citing equations, specify source: Paper 1 (Near-Wall) or Paper 2 (Ultra-Precise)
- Keep derivation steps explicit — show unit conversions
